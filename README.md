# Course Manager

یک اپلیکیشن سبک و کامل برای مدیریت درس‌ها، برنامه هفتگی، پروژه‌ها، امتحانات، فلش‌کارت و پیگیری مطالعه.
‌‌‌‌‌‌‌

## ویژگی‌ها

- **داشبورد هوشمند**  
  نمایش کلاس‌های امروز، تسک‌های نزدیک، امتحانات هفته جاری، آمار مطالعه و یادداشت‌های اخیر

- **مدیریت دروس**  
  افزودن درس با نام، کد، استاد و رنگ اختصاصی + پیگیری پیشرفت و موضوعات

- **برنامه هفتگی**  
  ثبت جلسات کلاسی برای هر روز هفته

- **پروژه‌ها و امتحانات**  
  مدیریت تسک‌ها با اولویت و وضعیت + ثبت آزمون‌ها (کوییز، میان‌ترم، پایان‌ترم)

- **تقویم ماهانه**  
  مشاهده تمام رویدادها (کلاس، ددلاین، امتحان، جلسه مطالعه) در یک نگاه

- **فلش‌کارت با الگوریتم فاصله‌گذاری**  
  ساخت دسته‌ها، افزودن کارت و مرور هوشمند (Again / Hard / Good / Easy)

- **ردیاب مطالعه**  
  ثبت مدت زمان مطالعه برای هر درس + آمار هفتگی و کلی

- **یادداشت‌های چسبان**  
  یادداشت‌های رنگی با امکان اتصال به درس

- **حالت تاریک / روشن**  
  پشتیبانی از تم سیستم + تغییر دستی

- **کاملاً آفلاین**  
  تمام داده‌ها در `localStorage` مرورگر ذخیره می‌شوند

---

## نحوه استفاده

1. فایل `Course Manager.html` را دانلود کنید
2. آن را با هر مرورگری باز کنید (Chrome, Firefox, Edge, Safari)
3. نیازی به نصب نیست

---

## ساختار داده‌ها

داده‌ها با کلید `uni-manager-v1` در LocalStorage ذخیره می‌شوند و شامل موارد زیر هستند:

| بخش          | توضیح                              |
|---------------|------------------------------------|
| `courses`     | دروس                               |
| `sessions`    | جلسات کلاسی                        |
| `tasks`       | پروژه‌ها و تسک‌ها                  |
| `exams`       | امتحانات                           |
| `notes`       | یادداشت‌های چسبان                  |
| `study`       | جلسات مطالعه                       |
| `decks`       | دسته‌های فلش‌کارت                  |
| `cards`       | کارت‌های فلش‌کارت                  |

---

## میانبرهای صفحه‌کلید (بخش فلش‌کارت)

- `Space` → نمایش پاسخ
- `1` → Again
- `2` → Hard
- `3` → Good
- `4` → Easy
